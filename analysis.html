OBJECT DISSECTION / MACHINE READING

Each vase is read from pixels alone: the background is modelled from the photo's edges and flood-filled away to leave a silhouette; surface texture is measured with an edge filter; five dominant colours are found by k-means clustering; the densest-texture patch becomes the pattern and the patch most unlike the rest of the object becomes the interesting element.
